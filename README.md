# Blue Vinyl

2026 FALL KAIST ID UXD project web prototype

Blue Vinyl - Auditory Trace for your own journey

## 시작하기

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 배포용 파일은 `npm run build`로 만든 `dist`에 있습니다. `npm run preview`로 빌드를 확인할 수 있습니다.

## 사용 흐름

1. **+ Add New Album**을 눌러 빈 LP를 엽니다. LP 가운데를 누르고 **Enter information**을 골라 이름, 일정, 장소를 입력한 뒤 **Save**를 누릅니다.
2. 저장 직후 열리는 순간 기록 화면에서 가운데 원을 눌러 사진을 찍고, **노래 추가**로 그날 들은 노래와 오디오를 기록합니다. 기록 날짜는 기기의 오늘 날짜로 자동 설정됩니다. 오른쪽 위 여행 메뉴에서 영상과 현장 녹음을 추가하거나, LP 화면 또는 선반으로 돌아갈 수 있습니다.
3. **PRESS INTO LP**로 새 기록을 담으면 LP 화면으로 돌아가고 소리골 한 줄이 새겨집니다. LP판을 누르면 다음 순간을 기록할 수 있습니다. LP 메뉴의 **오늘의 트랙 감상**에서 트랙을 재생하고 편집합니다. 사진 트랙은 자체 사진을 기본으로 쓰며, 각 트랙에 다른 사진을 지정할 수 있습니다.
4. LP 가운데를 누르고 **Finish my journey**를 고릅니다. 두 옵션은 110도 간격이며, 바로 누르거나 휠을 돌려 고를 수 있습니다. 종료를 확인하고 **Press!** 화면을 길게 누르면 사진이 LP 가운데에 들어갑니다. 배송 화면에서 위치 사용을 허용하면 가까운 도시와 거리에 따른 도착 예정일을 채웁니다. 두 값은 직접 수정할 수 있습니다. **OK**를 누르면 홈으로 돌아갑니다. 도착일이 되면 LP가 홈 선반에 표시됩니다.
5. 선반에서 LP를 선택한 뒤 레코드를 오른쪽으로 당겨 놓으면 열립니다. 홈의 턴테이블에는 도착한 LP 중 가장 최근에 완성한 LP가 놓입니다. 톤암을 왼쪽으로 끌어 LP 위에 놓으면 오디오가 재생되고, 오른쪽으로 빼면 정지합니다. 판을 누르면 앨범을 열 수 있습니다.
6. 받은 LP가 있을 때 홈에 종이비행기가 나타납니다. 비행기를 누르면 도착한 LP를 바로 재생하거나 내 선반에 저장하거나 버릴 수 있습니다.
7. 완성된 LP의 오른쪽 위 종이비행기를 눌러 여행지로 보내는 화면을 엽니다. **여행지로 보내기**를 누르면 지도에서 종이비행기가 날아갑니다. 이 화면에서 앨범 파일을 저장하거나, 웹에 올린 앱에서 작은 LP의 공유 링크를 만들 수 있습니다.
8. 재생 화면에서 두 손가락을 벌리거나 **LP 확대**를 누르면 오디오 트랙이 시간순으로 핀에 표시됩니다. 핀을 선택하고 **이 순간 재생**을 누릅니다. 노래를 추가할 때 들은 시간을 지정할 수 있으며, 시간을 비워 두면 추가 시각을 사용합니다. **Paris, France**의 샘플 LP에서 세 순간을 체험할 수 있습니다.

앨범과 미디어는 같은 브라우저의 IndexedDB에 저장됩니다. 녹음과 위치 확인에는 브라우저 권한이 필요합니다. 위치 좌표는 브라우저 안에서만 계산에 사용하며, 도착지 이름과 날짜만 저장합니다. 배송 날짜는 앱 안에서 사용하는 거리 기반 예정일입니다. 지도와 도시 데이터는 [Natural Earth](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2)에서 가져왔습니다. 샘플 사진과 소리는 이 앱의 시연용으로 제작했습니다.
